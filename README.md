# Sharvan M — Portfolio Website

A responsive, dark-themed portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally

1. Extract the `portfolio` folder.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.

No build step or package installation is required. Google Fonts and Font Awesome are loaded from CDNs; the rest of the site is static.

## Publish with GitHub Pages

1. Create a repository for the website (for example, `sharvan-m.github.io`) or use any repository with GitHub Pages enabled.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
5. GitHub Pages will publish the website at the URL shown in the Pages settings.
